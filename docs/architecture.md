# Архитектура

## Текущая версия (демо)
```
Браузер
 └─ frontend/index.html  — разметка и стили чата
 └─ frontend/app.js      — логика чата (отправка, рендер, индикатор)
 └─ frontend/mock.js     — заглушка «ИИ»: ответы по ключевым словам
```
Сервер не нужен, всё работает в браузере.

## Целевая версия
```
Браузер (frontend)  ──POST /api/chat {messages}──▶  Бэкенд (Python/FastAPI)
                    ◀──────── {reply} ───────────    └─ LLM API (выбор модели — на следующем этапе)
```
- API-ключ модели хранится только на бэкенде.
- Системный промпт задаёт роль: «советчик по путешествиям, отвечай кратко, структурированно, указывай время и бюджет».
- В `app.js` заглушка заменяется одной функцией `getReply(messages)`, поэтому фронтенд менять почти не нужно.

## Контракт API (план)
`POST /api/chat`
```json
{ "messages": [{ "role": "user", "content": "Что посмотреть в Риме?" }] }
```
Ответ:
```json
{ "reply": "..." }
```
