# Запуск и конфигурация

## Требования

- Python 3 для раздачи файлов через HTTP.
- Современный настольный браузер с JavaScript, `dialog`, `fetch` и `localStorage`.
- Node.js 18+ только для автотестов.

## Запуск из нового клона

```bash
git clone https://github.com/ChEh0V/Travel-AI-Assistant.git
cd Travel-AI-Assistant
python -m http.server 8000 --directory app
```

Открыть `http://localhost:8000/#chat`. Остановка — Ctrl+C в терминале сервера. Если порт занят, выбрать, например, `8012`. Команды выполняются из корня репозитория, а не из `app/`. Сборка, npm install, Docker, `.env` и секреты не требуются.

## Внешние зависимости

| Сервис | Назначение | При недоступности |
|---|---|---|
| Open-Meteo | Прогноз по координатам города и общим датам | Базовые сборы остаются, численные значения не подставляются |
| Google Fonts | Шрифт Manrope | Системный шрифт |
| Google Maps | Открытие места, отзывов и последовательности остановок | Пользователь остаётся с локальным планом |
| Официальные билетные сайты | Переход к покупке у выбранных объектов | Нет покупки и проверки наличия внутри приложения |

Погодный запрос реализован в `app/companion-ui.js`: ограничение ожидания 12 секунд, проверка полноты ответа, отмена при смене контекста. Интерфейс допускает даты в пределах 16 дней от текущего дня; доступность фактического ответа зависит от сервиса. Ключ LLM в браузер не добавляется; будущая серверная конфигурация будет описана вместе с backend.

## Решение проблем

| Симптом | Что проверить |
|---|---|
| Страница не открывается | Сервер запущен, адрес и порт совпадают с терминалом |
| 404 или список файлов вместо приложения | Сервер запущен из корня с `--directory app` |
| После смены порта нет поездок | Вернуться на прежний origin: хранилища изолированы |
| Изменения внешнего вида не видны | Обновить страницу с Ctrl+F5 |
| Погода не загружается | Даты, сеть и сообщение ошибки; базовые сборы доступны независимо |
| Изменения поездки не сохраняются | Разрешено ли локальное хранение и не исчерпана ли квота браузера |

Команды проверки приведены в [README](../README.md); ожидаемые действия — в [сценариях](../spec/product/scenarios.md). Отдельного production-развёртывания и серверного логирования пока нет.
