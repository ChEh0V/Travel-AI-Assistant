# Проверка качества RAG

## Статус

Корпус, BM25, LLM и runner ещё не реализованы. Числовых результатов качества нет. [questions.json](questions.json) — исторический черновик, а не готовый эталон: вопросы про Токио не относятся к выбранной области Европы, факты о бесплатном посещении не подтверждены корпусом. Этот файл нельзя использовать для приёмки без переразметки.

## Подготовка рабочего набора

После отбора корпуса заменить черновик вопросами по европейским направлениям. Для каждого вопроса сохранить ID, текст, контекст предыдущих сообщений, релевантные ID документов/фрагментов и ожидаемые подтверждённые факты. Отдельно включить отсутствие данных, смену города и запросы актуальных цен без источника. Отсутствие эталонной разметки не обозначать как ожидаемый отказ.

## Метрики и результат

- Recall@5: доля релевантных документов, найденных среди первых пяти; рассчитывается для вопросов с размеченными релевантными документами.
- Подтверждённость фактов и корректность ссылок в ответе.
- Правильный отказ при отсутствии сведений и сохранение контекста уточнений.

До итогового прогона зафиксировать выборки и целевые значения. В результатах сохранять версию корпуса и кода, параметры поиска, модель и настройки генерации, ответы по вопросам, метрики и ошибки. Команда запуска появится вместе с runner; сейчас её нет. Текущий [статус](results/2026-10-22-status.json) — `not_run`.
