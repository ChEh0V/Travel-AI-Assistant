# RAG: поиск и генерация ответа

## Корпус
- Markdown-файлы путеводителей по городам: `corpus/<город>.md` (Рим, Париж, Токио, Стамбул на старте).
- Разделы: достопримечательности, маршруты, бесплатное, еда, сезон.
- Документы режутся на фрагменты по заголовкам (≈ 100–300 слов).

## Индекс
- BM25 (Okapi), параметры по умолчанию: k1 = 1.5, b = 0.75.
- Предобработка: нижний регистр, токенизация, удаление стоп-слов, лемматизация для русского (pymorphy).
- Индекс строится при старте бэкенда и хранится в памяти.

## Поиск
- Запрос = последний вопрос пользователя + город из истории диалога, если в вопросе его нет («А что бесплатно?» → «бесплатно Рим»).
- Возвращаем top-5 фрагментов.
- Если лучший скор ниже порога — ответ «в путеводителях этого нет», без генерации.

## Генерация
- Промпт: роль советчика, вопрос, найденные фрагменты, требование отвечать только по ним и указывать источник.
- Модель выбирается на следующем этапе.

## Benchmark
- `benchmark/questions.json`: вопрос, ожидаемый документ, ключевые факты ответа.
- Метрики: Recall@5 по документам (поиск), доля ответов с ключевыми фактами (генерация).
- Результаты прогонов сохраняются в `benchmark/results/`.

## Уточнение области — 2026-10-21
Продукт ограничен Европой; Токио исключён из планируемого корпуса. Окончательные города и источники не утверждены. Шесть городов во фронтенде — демонстрационные данные, не готовый корпус. Ранее предложенные порог BM25, параметры и метрики требуют проверки после появления корпуса; фиксированный универсальный порог сейчас не заявляется.
