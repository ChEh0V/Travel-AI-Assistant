# Travel AI Assistant

Чат-советчик по путешествиям. Ищет ответы в корпусе путеводителей через BM25 и формирует ответ с помощью LLM: что посмотреть в городе, маршрут на несколько дней, что бесплатно, где поесть.

## Задача

Турист тратит часы на блоги и форумы, чтобы спланировать поездку. Мы даём один чат: вопрос → найденные фрагменты путеводителей → короткий ответ с источниками.

## Пользователь

Турист, который едет в незнакомый город на 1–3 дня и хочет быстро понять, что посмотреть и как построить маршрут.

## Основной сценарий

Вопрос → найденные документы → ответ.

1. Пользователь пишет: «Что посмотреть в Риме за 2 дня?»
2. Система находит подходящие фрагменты путеводителей (BM25).
3. LLM формирует маршрут по дням на основе найденного.
4. Пользователь уточняет: «А что бесплатно?»

## Запуск

```bash
git clone https://github.com/ChEh0V/Travel-AI-Assistant.git
cd Travel-AI-Assistant
python -m http.server 8000 --directory app
```

Открыть http://localhost:8000. Можно и просто открыть `app/index.html` в браузере.

Тесты:

```bash
node --test
```
