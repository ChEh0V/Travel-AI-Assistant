# Travel-AI-Assistant

ИИ-советчик по путешествиям: чат, в котором можно спросить, что посмотреть в городе, куда сходить, как спланировать маршрут на несколько дней и когда лучше ехать.

## Цель

Помочь путешественнику быстро получить понятный совет по достопримечательностям и маршруту, без часов поиска по форумам и путеводителям.

## Пользователь

- Турист, который едет в незнакомый город и хочет понять, что посмотреть за 1–3 дня.
- Студент или путешественник с ограниченным бюджетом, которому важны бесплатные места и советы по экономии.
- Человек, который выбирает направление и хочет сравнить несколько городов.

## Базовый сценарий

1. Пользователь открывает чат.
2. Пишет вопрос, например: «Что посмотреть в Риме за 2 дня?» Можно нажать готовую подсказку.
3. Ассистент отвечает списком мест, коротким маршрутом и практическими советами.
4. Пользователь уточняет: «А что бесплатно?», «Где поесть?»

## Запуск

Фронтенд — одна статическая страница без сборки:

```bash
git clone https://github.com/ChEh0V/Travel-AI-Assistant.git
cd Travel-AI-Assistant
```

Откройте `frontend/index.html` в браузере (двойным кликом) или запустите локальный сервер:

```bash
python -m http.server 8000 --directory frontend
```

и перейдите на http://localhost:8000.
